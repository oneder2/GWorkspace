# 展品优先的参观路径

2026-09-29。先将上一轮实现提交为 `2262514`（dev）/ `a151d7c`（main），发布管理前端、后端和 Gellaria；随后完成本轮开发。GWorkspace 仍是公开事实的唯一来源，未修改其他产品仓库。

## 内容与入口

- 抵达页「选择参观方向」及地图提供看作品、读文章、听回声三个实际入口。仍可从岛上走近建筑按 E。
- 工坊「从一件作品开始 · 参观指南」提供 CiteAI、Vana、Oceannect 的直接近看入口；只从当前公开展出的数据中选择，不复活隐藏或撤回条目。指南也列出当前组的全部展室。
- 三件代表作品沿用已有功能演示：论断与引用、本地文档与同步、伴侣节点与记忆。近看首先说明项目用途和个人角色，明确演示是示意；展签按用途、个人参与与实现、实际入口组织内容，模型寓意折叠。
- 角色、参与方式、实现记录、日期、链接、封面及图集均来自 GWorkspace 项目记录。没有新增虚构业务指标或第二份内容库。当前三件作品使用已有界面截图作为封面，图集在有公开图片时显示。
- world 与 catalog 均返回 `details: {role, involvement, start, end, highlights, links, gallery}`。新增字段兼容旧响应；目录访问不再依赖 resume 的附加数据或条目上限。未发布图集图片被过滤。
- 阅览厅以长文为首要展出，按主题分室，每日赠语独立置后。回声林地仍以偶遇、停留、暂停阅读呈现留言与声音。

## 空间取舍

保留工坊的冷色金属、铜色提示与工作台，保留阅览厅的靛蓝、暖木书案与低书架。提亮背景、地面和环境光；侧墙降低到 1.3 单位，隔断降低到 0.5 单位。移除高展品背板、装饰拱环、密集地面条纹、重复柜体和悬空灯具模型。聚光、方向光阴影、遮挡淡出与展品近看继续保留。

展品向通道靠近，中央仍保留至少 4.7 单位的通行宽度（含角色避让缓冲）。低矮边界和较少装饰让展品轮廓优先，未更换室外建筑或林地模型。

## 发布与验证

第一轮后端部署脚本在启动后固定等待三秒，早于回填完成，导致健康检查误报失败；随后公开 health、catalog 与模型响应均正常。修正为启动前执行模型回填、对健康检查进行有限重试。更新 fast-uri、morgan、multer 的兼容安全修复，前后端审计均无漏洞。CI 增加模型生命周期与策展检查。

本地通过 18 文件 / 66 项 Gellaria 测试、TypeScript、lint、world 兼容、简历兼容、模型生命周期、策展、后端路由和安全检查。新增验证覆盖目录和入口详情一致、英文角色、草稿图片过滤、相对图片代理地址、长文与赠语顺序、展台与通道间距。
